## 建立"代码改动可回退备注规范"（用户拍板）
- 背景：用户曾因 AI 改代码出 bug、改动未 commit 堆在工作区，无法按时间点回退。
- 决策：
  1. commit 节奏 = **小步多次**（每次改完就提，不攒未提交改动）。
  2. 代码标记 = 启用 `// >>> CHANGE-[YYYY-MM-DD HH:MM:SS]-[主题] 开始` … `// <<< CHANGE-[同时间戳]-[主题] 结束` 成对秒级时间戳标记。
  3. 时间戳与 git commit 时间对齐，便于互相印证。
- 已写入 MEMORY.md 长期记忆（标题"代码改动可回退备注规范"）。
- 回退速查：`git revert <hash>` / `git checkout <hash> -- 文件` / `grep -rn "CHANGE-\[日期" AIA/AIA/`。
- 注意：Xcode 无 Local History 功能，勿误导用户去 Xcode 找。
