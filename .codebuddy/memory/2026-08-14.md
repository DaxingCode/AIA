  4. `ContentView.swift` 第 266 行灯泡按钮：改 `presentInAppBrowser(AppURLs.featureIntro)`，与隐私政策/用户协议同一套兜底。

## LoginView《用户协议》《隐私政策》链接不跟随云端修复（方案 B）
- 现象：开发者中心改了协议链接保存上云，登录页两个链接仍跳老地址。
- 根因：`fetchConfig`（拉云端配置）只在设置页/首页触发，登录页不在触发时机里，且 `LoginView` 没订阅 `GlobalConfigStore` 变化；`AppURLs.userAgreement/privacyPolicy` 是计算属性，但读的时刻内存里还是旧值。
- 修法（`LoginView.swift`，已 xcodebuild BUILD SUCCEEDED 验证）：
  1. 加 `import Combine`。
  2. body 末尾加 `.onReceive(GlobalConfigStore.shared.objectWillChange) { _ in }` —— 云端配置一变，视图重算，计算属性立即重读新链接。
  3. 加 `.task { await GlobalConfigStore.shared.fetchConfig() }` —— 进登录页也拉一次，补「停在登录页时云端被改」的刷新缺口（与首页同套路）。
- 关键：`AppURLs` 三个链接都是计算属性（云端优先、空=CloudBase 默认域名兜底），订阅重算即自动跟随，无需额外传值。
