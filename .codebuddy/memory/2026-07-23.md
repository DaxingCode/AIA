## 修复模拟器同步失败：HTTP 413（task #aia-parallel-team / bug-fixer）

- **现象**：模拟器测试同步失败（HTTP 413 Payload Too Large），真机同步成功。
- **根因**：`CloudSyncManager.syncAfterLogin()` 登录后**先 pull 后 push**，pull 把云端全部历史写入本地，push 又把这批数据打包发回云端，单批请求体随历史数据量膨胀，超过 CloudBase HTTP 触发器 ~1MB 限制 → 413。模拟器是全新构建后立刻登录，pull 回大量云端历史（含多条 RecognitionRecord.rawText 1-5KB/条）最易触发；真机因已分批同步过、增量小，未触发。
- **修复**（`AIA/AIA/CloudSyncManager.swift` `push()`）：改为**分批推送，每批 200 条**，单批请求体通常 < 200KB 安全通过；按 syncId 维度天然幂等，多批不重复。日志打印 `push 第 N/M 批（X 条）完成`。
- **验证**：用户模拟器重新登录后测试，同步成功（已确认）。
- **结论**：413 是请求体积问题，非删除不跨设备等已知设计限制所致；分批方案通用，真机大量数据场景同样受益。
