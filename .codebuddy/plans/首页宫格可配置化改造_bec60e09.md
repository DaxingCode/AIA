## 首页模块可配置化改造

将首页当前的固定四宫格（饮食/健康/账单/待办）+ 今日事项预览气泡改为可配置布局，支持用户调整模块顺序和显示/隐藏。

### 核心功能

1. **模块枚举**：定义 `HomeModule`（diet, health, bill, todo, aiSummary），带 `layout` 属性（.gridCard 或 .fullRow）
2. **HomeLayoutStore 单例**：用 `ObservableObject` 管理顺序与隐藏状态，底层存 UserDefaults（不跨云同步），初始化做差集补齐确保新增模块自动可见
3. **分段渲染器**：替换硬编码的 `tilesGrid` + `aiSummarySection`，遍历 `order` 连续 gridCard 累积进一个 LazyVGrid，遇 fullRow 先渲网格再渲整行
4. **编辑入口两套**：设置页 `HomeLayoutSettingsView`（List + .onMove + 隐藏 Toggle + 恢复默认按钮）+ 首页长按进入编辑态（抖动、挂隐藏减号、可拖拽重排）
5. **添加模块**：编辑态底部入口列出已隐藏项，点选恢复；设置页用 Toggle 控制
6. **空态兜底**：全部隐藏时显示「暂无可显示模块」提示
7. **宽屏预埋**：`LayoutTier` 枚举已定义，默认 compact，不开放 UI 切换

### 保持不变

- header 问候语与 syncHeaderIndicator 固定不动
- `animatedTile` 动画效果保留
- 数据源与数据流（@Query、AISummary、四个 tile 的内容逻辑）不变

## 技术方案

### Tech Stack

- 纯 Swift + SwiftUI + SwiftData（iOS 17+），保持项目现有技术栈不变
- 存储：UserDefaults（通过 `@AppStorage` 配合 JSON 编解码），不跨云同步

### 实现方案

#### 1. 新文件 HomeLayout.swift

定义 `HomeModule` 枚举（CaseIterable, Identifiable, Codable）与 `HomeLayoutStore` 单例（ObservableObject）。初始化逻辑：

- 从 UserDefaults 读取已存 order，用 `HomeModule.allCases` 做差集补齐（新 case 追加末尾且默认可见）
- hidden 为空 Set → 老用户升级首页零变化
- 提供 `toggleHidden(_:)`、`move(from:to:)`、`resetToDefault()`、`visibleOrder` 计算属性
- 每次写 UserDefaults 后调用 `objectWillChange.send()` 确保 UI 刷新

#### 2. 修改 ContentView.swift

- 添加 `@StateObject private var homeLayout = HomeLayoutStore.shared` + `@State private var isEditingHome = false`
- body 中将 L82-L98 的 `tilesGrid` + `aiSummarySection` 替换为分段渲染器 `homeModulesView`
- 分段渲染器逻辑：遍历 `homeLayout.visibleOrder`，连续 .gridCard 积累进一个 LazyVGrid（2列），遇 .fullRow 先渲网格再渲整行。渲染各模块时调用保留的 `dietTile`/`healthTile`/`billTile`/`todoTile` 及 `aiSummaryContent`
- 编辑模式：模块左上角叠加红色减号按钮（`toggleHidden`）、整块抖动效果（`.phaseAnimator`）、整块可拖拽（`.onDrag`/`.onDrop`）
- 顶栏新增「编辑/完成」按钮切换 `isEditingHome`
- 宫格区域加长按手势（`LongPressGesture(minimumDuration:0.5, maximumDistance:10)` + `.simultaneousGesture`）进入编辑态
- 编辑态全隐藏时显示空态提示
- 编辑态底部「+ 添加模块」入口，Sheet 弹起列表选中恢复

#### 3. 新文件 HomeLayoutSettingsView.swift

- List 驱动 `HomeLayoutStore.shared.order`，每行显示模块名 + 隐藏 Toggle
- `\.onMove` 调 `store.move(from:to:)`
- 底部「恢复默认布局」按钮调 `store.resetToDefault()`
- 保持 SettingsView 通用卡片样式（VStack + .card()）

#### 4. 修改 SettingsView.swift

- 在 `appearanceCard` 后新增 `homeLayoutCard`，NavigationLink 到 `HomeLayoutSettingsView`
- 复用现有卡片视觉模式（`VStack(alignment:.leading,spacing:12)` + icon + title + `.card()`）

#### 5. 备份与安全

- 不改动 `tile(...)` 通用卡片构造器（L635-L728）、`dietTile`/`healthTile`/`billTile`/`todoTile` 内容、`AISummary` 文案（UIComponents.swift L823-L898）
- 不改动数据层（@Query、HealthMetric、Router）、动画流程、导航逻辑

### 架构设计

#### 数据流

```
用户操作（拖拽/隐藏/恢复）
    ↓
HomeLayoutStore（单例 ObservableObject）
    ↓  objectWillChange 响应
ContentView / HomeLayoutSettingsView 重新渲染
    ↓
分段渲染器按 visibleOrder 逐块渲染
```

#### 模块依赖关系

```
SettingsView → HomeLayoutSettingsView（NavigationLink）
ContentView  → HomeLayoutStore.shared（读取 order/hidden）
             → 分段渲染器（渲染 gridCard + fullRow）
             → 编辑模式（长按/顶栏按钮触发）
```

### 关键实现细节

1. **存储格式**：order 存为 `[String]`（模块 rawValue 数组），hidden 存为 `[String]`（隐藏模块 rawValue 数组），均通过 `UserDefaults.standard.array(forKey:)` + `JSONEncoder`/`JSONDecoder` 读写

2. **分段渲染核心逻辑**：

```
for (i, module) in homeLayout.visibleOrder.enumerated() {
    if module.layout == .gridCard {
        gridBatch.append(module)  // 累计
    } else {
        if !gridBatch.isEmpty { renderGrid(gridBatch); gridBatch = [] }
        renderFullRow(module)     // 渲染 aiSummary
    }
}
if !gridBatch.isEmpty { renderGrid(gridBatch) }
```

3. **兼容性**：老用户无存储数据 → init 产生 `HomeModule.allCases` 默认 order + 空 hidden → 与现在完全一致，升级零变化

4. **动画保留**：分段渲染的 gridCard 部分继续使用 `animatedTile(_:tile:)`，以 `.delay(Double(idx) * 0.06)` 保持进场动画

5. **编辑态抖动**：用 `.phaseAnimator([0, 1])` 每 0.15s 交替 1-2 度旋转，配合红色减号 overlay
