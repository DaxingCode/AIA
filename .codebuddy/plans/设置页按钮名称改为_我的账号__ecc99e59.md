## Product Overview

修改设置页面中「我的账号」卡片的默认显示名称

## Core Features

- 将设置页第一个按钮（账号卡片）的默认显示文案从「小记的朋友」改为「我的账号」
- 仅改显示文案，不影响原有功能和跳转逻辑
- 涉及 SettingsView.swift 中两处字面量：@AppStorage 默认值 + Text fallback 文案

## Tech Stack

- 纯 SwiftUI 文案修改，无架构变更

## Implementation Notes

- 修改文件：`AIA/AIA/SettingsView.swift`
- 改动点 1（第 15 行）：`@AppStorage("userNickname") private var userNickname = "小记的朋友"` → 默认值改为 `"我的账号"`
- 改动点 2（第 199 行）：`Text(userNickname.isEmpty ? "小记的朋友" : userNickname)` → fallback 文案改为 `"我的账号"`
- 注意：ContentView.swift 和 MyAccountView.swift 中也有相同字面量，但用户明确只改设置页面，暂不动其他位置（若需全局统一可后续处理）
