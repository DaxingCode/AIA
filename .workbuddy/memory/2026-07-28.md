## 18:37 · 修复未授权 HealthKit 时健康数据「清零」问题
- 问题：用户反馈没有授权 HealthKit 的情况下，健康管理页的步数/睡眠/运动时长每天 0 点自动清零。
- 根因分析：
  1. `usesHealthKit` 原来只判断 `health.authorized`。HealthKit 的 `requestAuthorization` 回调里的 `success` 只表示「授权弹窗已展示」，不代表用户真的允许。若用户点拒绝，回调 `ok=true` 会让 `authorized=true`，随后 UI 改用 HealthKit 数据（读不到 → 全 0），手动录入值被忽略。
  2. `ContentView.swift` 的 `aia.exerciseMinCurrentManual` 声明为 `Double`，而 `RecordsViews.swift` 声明为 `Int`，同一 UserDefaults key 类型不一致会导致读写失败、数值异常/归零。
- 改动：
  - `AIA/AIA/HealthManager.swift`：新增 `@Published var hasHealthKitData = false`，四个 fetch 回调在读到非零数据时置 `true`。
  - `AIA/AIA/ContentView.swift`：`usesHealthKit` 改为 `health.authorized && health.isAvailable && health.hasHealthKitData`；`exerciseMinCurrentManual` 类型统一为 `Int`；计算公式相应转 `Double`。
  - `AIA/AIA/RecordsViews.swift`：`usesHealthKit` 同步改为 `health.authorized && health.isAvailable && health.hasHealthKitData`。
- 效果：未真正读到 HealthKit 数据时（未授权/被拒绝/无 entitlement/模拟器），圆环与首页健康卡片回退到手动录入值，不会因授权弹窗状态误判而显示全 0；运动时长手动值在首页与健康管理页类型一致，可正常同步。
- 验证：xcodebuild BUILD SUCCEEDED。改动尚未 commit。

## 18:57 · 修复手动健康数据跨天仍显示「昨天数据」问题
- 问题：用户追问「怎么步数、睡眠、运动时间显示的还是昨天的数据？」——未授权 HealthKit 时，手动录入的步数/睡眠/运动时长在跨天后仍显示前一天数值。
- 根因：旧代码把手动值存在单一全局 `@AppStorage` key（`aia.stepsCurrentManual`/`aia.sleepHoursCurrentManual`/`aia.exerciseMinCurrentManual`），无日期维度，跨天不归零，今天读到的还是昨天存的值。
- 改动：
  - 新增 `AIA/AIA/ManualHealthStore.swift`：`final class ManualHealthStore`，按 `Calendar.current.startOfDay(for:)` 日期维度存 UserDefaults（key 形如 `aia.manualHealth.steps.\(dayTimestamp)`）。提供 `steps`/`sleepHours`/`exerciseMinutes` 的 `for:` 读取与 `set`/`add` 方法；`init()` 里 `removeObject` 清理旧全局 key，避免旧值污染。
  - `AIA/AIA/ContentView.swift`：移除三处 `@AppStorage` 手动值声明；`homeSteps`/`homeExerciseMin`/`sleepLastNight` 改用 `ManualHealthStore.shared.xxx(for: Date())`（Date()=今天）。
  - `AIA/AIA/RecordsViews.swift`：移除三处 `@AppStorage` 手动值声明；`stepsCurrentValue`/`sleepCurrentValue`/`exerciseCurrentValue` 改用 `ManualHealthStore.shared.xxx(for: Date())`；`incrementMetric` 的 `+N` 写入改用 `addXxx(_:for: Date())`。
- 效果：手动录入值按天隔离，每天 0 点自然归零（今天读今天、昨天读昨天），不再把旧日期数据带过来；旧全局 key 自动清理，无脏数据。
- 项目用 `PBXFileSystemSynchronizedRootGroup` 自动同步 `AIA/AIA/` 文件夹，新增 `ManualHealthStore.swift` 无需改 pbxproj 即可编译。
- 验证：xcodebuild BUILD SUCCEEDED。本轮所有改动（HealthKit 三重校验 + 类型统一 + ManualHealthStore 按日期隔离）尚未 commit，待用户确认后提交。
