## 启动屏预览 HTML → PNG
- 用户要把 `launch_screen_preview.html`（带设备外框的预览）做成 PNG 用作 App 启动屏。
- 关键判断：启动屏不能用带手机外框的图，须全屏铺满。故重绘为全屏启动图：浅色背景 #f7f9fb + 居中绿色「記+AI」图标（取自真实 AppIcon.png）+ 标题「好记AI」(#3c3c43) + 页脚「自动记账记待办，管理饮食和健康」(#8a9099)，加绿色同色辉光。
- 渲染脚本 `AppIcons/render_launch_screen.py`（PIL，按 390x844 逻辑点 @3x 等比适配，输入 W/H 任意）。
- 本机无 PingFang，用 Hiragino Sans GB（标题 W6 index=2 半粗、页脚 W3 index=0 常规）。
- 产出：`AppIcons/LaunchScreen_1170x2532.png`（iPhone12/13/14 @3x）、`LaunchScreen_1290x2796.png`（Pro Max @3x），及各自 `_preview.png` 缩小预览。背景色抽查 (247,249,251) 正确。
- 提醒用户：iOS 推荐 LaunchScreen.storyboard 而非静态 PNG（LaunchImage 已废弃、需多尺寸）；已提议帮做 storyboard 或补全套静态尺寸，待用户定。
