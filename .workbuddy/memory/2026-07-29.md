## 14:40 · 关键发现：/sync、/recognize 路由是「CloudBase 控制台函数触发方式里的 HTTP 触发」建的，不是 HTTP 网关手动路由
- 溯源：`云函数/aia-sync/deploy.sh`（2026-07-17）写明「云函数 aia-sync → 新建 HTTP 触发，路径 /sync，集成响应开关与 /recognize 一致」。说明 /sync、/recognize 都是 CloudBase 云开发控制台「函数管理 → 函数 → 触发方式 → 新建触发 → HTTP 触发 + 自定义路径」建出来的。
- 用户之前一直进的是 **SCF 原生控制台**（`/scf/detail?fid=...`），那里没有 CloudBase 的「触发方式」入口；而「HTTP 网关」手动「添加路由」会被平台拒绝（系统内置域名不可手动创建/修改）。
- 正确部署路径（aia-ads 照做）：CloudBase 云开发控制台 → 云函数 → 函数管理 → aia-ads → 触发方式 → 新建触发 → HTTP 触发 → 路径 /ads → **集成响应必须关闭**（index.js 直接 return {ok,...} 明文 JSON，未包 {statusCode,headers,body}）。
- 结论：以后任何 aia 云函数要对外暴露 HTTP 路径，一律走 CloudBase 控制台「函数触发方式」建 HTTP 触发，不要走 HTTP 网关手动路由、也不要走 SCF 控制台。
