## 底部栏文案「永远停在问问阿宝AI 不切换」彻底修复

## UI 视觉动效优化（用户「按你建议的来」→ 卡片按压 / 玻璃栏 / 图表生长）
- 需求：用户要我按之前给的视觉优化清单落地，选了 3 件高价值项：① 卡片按压+抬升 ② 悬浮栏玻璃材质 ③ 图表描边/生长动画。
- 改动（`AIA/AIA/UIComponents.swift`）：
  - **动效令牌**：`AIATheme` 新增 `cardShadowStrong`、`static var motionReduce { UIAccessibility.isReduceMotionEnabled }`、`enum Motion { press=spring(0.32/0.6), draw=easeOut(0.8), progress=easeOut(0.6) }`。所有动画统一走令牌 + 自动尊重「减弱动态效果」。
  - **`PressableCardStyle: ButtonStyle`**：按下 `scaleEffect(0.97)` + 阴影抬升，松手 spring 回弹。**用 ButtonStyle 实现而非在 `.card()` 内加手势**——可 100% 避免项目铁律中「Button/overlay 吞点击」问题，与点击共存。
  - **`AIBottomBar` 玻璃化**：`.background(Color(.systemBackground))` → `.background(.ultraThinMaterial)`（保留顶部 Divider）。底部栏更轻盈有层次，自动适配明暗；仍作为 ScrollView 的 VStack 兄弟节点（遵守铁律，不改成 overlay 以免 iOS 26 白屏）。
  - **`RingView`/`DonutView` 描边生长**：各加 `@State` 插值系数，`onAppear` + `onChange(of: progress)` 从 0 描边生长到目标值（环 trim / 扇区从起点生长）。
  - **`MacroCard`/`MiniBar` 进度条生长**：`@State drawn` 从 0 生长到目标宽度，`onAppear` + `onChange(of:)`；`MiniBar` 用于列表（RecordsViews/BillCategoryView/ContentView），滚动进入视区时生长是其接受的 reveal 模式。
- 改动（`AIA/AIA/ContentView.swift`）：首页四宫格 `tile(...)` 的 `.buttonStyle(.plain)` → `.buttonStyle(PressableCardStyle())`，整张宫格按下即有缩放下沉反馈（空态「点击记录」提示不受影响）。
- 改动（`AIA/AIA/WeightTrendView.swift`）：`Chart` 进入用 透明度(0→1) + 轻微缩放(0.96→1, anchor 左) 淡入。`onAppear` 触发；**iOS 26 下 Swift Charts 路径描边动画不可靠，故用淡入替代真·描边生长**——稳定且观感一致。
