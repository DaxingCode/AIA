## 底部栏文案「永远停在问问阿宝AI 不切换」彻底修复

## 支付宝付款成功页 3 处识别错误修复

  娟            ← 真实商户
  付款方式

## 修时间提取 bug：状态栏「13:10 1」被反向跳过
- 现象：商户改对了，但时间还是 fallback 到 .now（用户截图显示 15:34，状态栏实际 13:10）。
- 根因 1（操作符优先级）：extractRelativeDateTime 上一版 skip 条件写的是
  `line.contains("：") || line.contains(":") && ...`，因 && 优先级高于 ||，实际求值为
  `A || (B && C && D)`，把"带冒号 + 无秒 + 非严格 HH:MM"的行**全跳过**——这正好把
  想匹配的「13:10 1」跳过了。改为只跳「带中文冒号『：』」的标签行。
- 根因 2（防御性救回）：主 OCR 的 `minimumTextHeight=0.008` 可能过滤掉状态栏小字。
  新增 `localOCRStatusBar`：单独 OCR 顶部 ~6% 区域，`minimumTextHeight=0`，
  把结果 prepend 到 cleanText 头部，让 extractISODateTime 第一个看到状态栏时间。
- 文件：`AIA/AIA/RecognizeService.swift`
- 编译：xcodebuild **BUILD SUCCEEDED**
- commit：`4be3de0`
