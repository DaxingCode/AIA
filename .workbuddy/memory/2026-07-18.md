## ⚠️ 首页动画不显示的根因修复（关键 bug）
- 文件：`AIA/AIA/ContentView.swift`
- 根因：`@State private var homeAppeared` 初始值被错设成 `true`，导致 `.onAppear` 里 `homeAppeared = true` 没有值变化，入场动画（opacity/offset + .animation(value: homeAppeared)）**永远不触发**——所有元素一进来就是最终状态，所以看不到任何动画。之前几轮加了统一弹簧、自下而上动画都没生效就是因为这个。

- 行为：仅首次进入首页播放入场动画；从子页面返回时 `homeAppeared` 已为 true，不再重播（避免每次返回都闪）。

## 图片识别报 HTTP 400 排查
- 文件：`AIA/AIA/RecognizeService.swift`、`原生代码脚手架/cloudfunctions/recognize/index.js`
- 现象：首页点击图片识别后弹窗「识别失败：请求失败 (HTTP 400)，请检查图片是否过大或云函数配置」。
- 根因定位：HTTP 400 是 **CloudBase 网关层**返回的，不是云函数代码里 `ok:false` 的 200 响应。函数代码里只有 `ok:false` 返回 200（如缺少环境变量、缺少字段），不会主动返回 400。常见触发点：
  1. **没重新部署最新 `归档.zip`**：旧版函数可能不兼容当前请求格式。
  2. **CloudBase HTTP 触发「集成响应」未关闭**：当前函数直接返回 `{ ok, result }` 对象，关闭集成响应时才被原样透传；开启时会因格式不符被网关拦成 400。
  3. 请求体过大（当前压缩后 < 100KB，可能性低）。
- 改动：
  - 优化 `RecognizeService` 三个请求（`recognize`、`parseText`、`chat`）的非 2xx 错误提示，把云端返回体前 200 字符也展示出来，并明确列出三条检查项：重新部署 zip / 关闭集成响应 / 环境变量。
- 验证：`AIA` scheme 模拟器 build → **BUILD SUCCEEDED**。
- 下一步：建议用户到 CloudBase 控制台 → 云函数 `recognize` → 触发管理 → HTTP 触发，确认「集成响应」开关为关闭状态，并重新上传 `原生代码脚手架/cloudfunctions/recognize/归档.zip` 后发布。

## 修复对话页逻辑错乱（AI 回复与用户消息错位 + 重复执行）
- 文件：`AIA/AIA/ChatView.swift`、`原生代码脚手架/cloudfunctions/recognize/index.js`、`原生代码脚手架/cloudfunctions/recognize/归档.zip`

## ⚠️ value 形式 NavigationLink 导致 iOS 26.5 白屏（关键教训）

  - 底部栏 chat/mic：不在 grid，闭包形式 `NavigationLink { ChatView() }` 正常，回退即可。
- 结论 / 长期约定：本项目（iOS 26.5 模拟器/真机）首页及任何 `LazyVGrid` 内，**不要用 `NavigationLink(value:)`**；跳转用 `Button { path.append(Route.xxx) }` 或闭包形式（非 grid 时）。`navigationDestination(for:)` 本身没问题（build A 曾正常显示）。

- 验证：本机无 Xcode 未 build；改完待用户 Clean Build Folder 后重测——四宫格点击应分别进入对应列表页。
