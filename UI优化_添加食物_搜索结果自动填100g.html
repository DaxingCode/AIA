点搜索结果 → weightText 显式重置 100g，营养成分 = 基础营养（65 kcal）。用户后续可再调重量。

🔍 关键改动

  1. 文件：AddFoodManualView.swift:525-528
  2. 改动：applySearchResult(_:) 入口加一行 weightText = "100"
    旧：name = result.name → 写基础营养 → 收尾
    新：name = result.name → weightText = "100" → 写基础营养 → 收尾
  3. 设计依据：搜索结果的基础营养都是按 100g 算的（NutritionLibrary/FoodMeta 标准化）， 选中 = "用 100g 基础营养填充表单"，与下方"营养成分（按当前重量）= baseKcal × 100/100 = baseKcal"语义自洽。
  4. 不破坏：用户后续可再手动改 weightText（如改成 250g），营养成分会按 250g 重新计算。

📋 行为闭环

1. 用户输入"牛奶" → 搜出"牛奶 65 kcal/100g"（内置库）
2. 用户点搜索结果 → name="牛奶"，weightText="100"，baseKcalText="65.0"
3. 营养成分自动 = 65.0 × 100/100 = 65 kcal（用户一眼能看到 65）
4. 用户想喝 250g → 改 weightText 为 250 → 营养成分自动 = 65.0 × 250/100 = 163 kcal
5. 点保存 → FoodEntry 写入（baseCalories=65, weightGram=250, calories=163）
