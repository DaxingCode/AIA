🔍 关键差异对照

  1. 金额占位：EditSheets.swift:609
    旧：_amountText = State(initialValue: String(format: "%.2f", bill.amount))（草稿 amount=0 → 文本 = "0.00" → 占位不显示）
    新：_amountText = State(initialValue: isAdding ? "" : String(format: "%.2f", bill.amount))（添加模式空 → TextField("0.00", ...) 显示占位灰字）
  2. 分类默认：RecordsViews.swift:1351
    旧：category: "其他"（显示 📦 其他，icon 偏冷门）
    新：category: "餐饮"（BillCategoryHelpers.icon("餐饮") = 😋，最常见且带 emoji）
  3. 保存兼容：EditSheets.swift:907
    bill.amount = Double(amountText) ?? bill.amount 兼容空字符串（用户没填金额时回退到 0.00，不崩）；bill.category = category 直接写回"餐饮"。
