设计要点

  • 热量上移标题栏：原本占一整行，现在合并到标题栏右侧琥珀色 pill「🔥 60 kcal」，按当前重量/份量实时联动（EditFoodView 加 displayedKcalText；AddFoodManualView 沿用 totalKcal）。
  • 2 行 × 3 列：6 大营养素（蛋白/碳水/脂肪/纤维/糖/钠）改为 LazyVGrid(.flexible × 3)，每格紧凑 cell：icon（6 色调色板） + 名称 + 输入框 + 单位。
  • 6 色调色板与全模块对齐：蛋白 blue / 碳水 amber / 脂肪 bill 绿 / 纤维 health 紫 / 糖 warn 警告红 / 钠 todo 深琥珀——与聊天确认卡 / 列表行 / 结果确认页 / 食物详情页严格一致。
  • cell 容器：fillSoft 灰底 + rXS(8pt) 圆角 + 10pt 内边距，等宽 3 列铺满卡宽。
  • 可访问性：每个 cell 仍有「图标 + 名称」双标识，仅看数值也能分辨归属；输入框沿用 decimalPad 键盘，数字键盘可关闭返回不丢值。

适用范围

  • EditFoodView（编辑已有食物记录，EditSheets.swift）
  • AddFoodManualView（手动添加食物，AddFoodManualView.swift，本次首次入仓）
